Expansion Target Ranking

Ranks every state outside Massachusetts and New Jersey (Doorman's existing markets) on five factors: Feasibility (30%), Decision-Window Timing (25%), Go-to-Market Concentration (20%), Legislative Direction (15%), and Market Size / TAM (10%). A state classified Restricted on the main tracker is excluded outright, regardless of score — see How It Works for the full methodology.

All five factors are fully automatic and recompute every night along with the rest of this tracker — there's no hand-maintained factor in this version. Feasibility and TAM come straight from the classification/enrollment data. Timing is a best-effort scan of enacted bill text for an effective-date signal. Go-to-Market Concentration reflects how Doorman actually sells — school by school, not district by district, per the investment memo — using each state's average high-school size relative to Doorman's 200–2,000-student ICP band. Legislative Direction reads each state's most-advanced pending bill through the same physical-storage/software-friendly keyword scan used on enacted law, so a state with several bills trending toward a hard pouch mandate scores as a risk, not an opportunity — bill count alone can't tell those apart. All of this is still directional, not a finished answer: a competitor's new product, a district pilot already underway, or a sales conversation in progress won't show up in any of these five factors.
